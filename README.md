# EJIS Terminal

Windows 11용 다중 세션 터미널입니다.

[최신 Windows 설치 파일 받기](https://github.com/brownailes/ejis-terminal-releases/releases/latest)

## 설치와 업데이트

1. 최신 릴리스에서 `EJIS-Terminal-버전-x64-setup.exe`를 받으세요.
2. 설치 파일을 실행하고 안내에 따라 설치하세요.
3. 앱이 Windows 업데이트 상태를 확인해요. 필요한 업데이트가 없으면 터미널 1로 바로 시작해요.
4. 이후 새 버전은 앱의 오른쪽 아래 알림 또는 ‘업데이트 확인’에서 받을 수 있어요. 설치 전에는 작업을 저장해 주세요.

소프트웨어 업데이트 확인과 Windows 운영체제 업데이트 확인은 별개예요.
